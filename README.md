# Mentors International AI Mentoring Pilot

This repository contains the source code for the AI Mentoring Tool pilot for Mentors International.

## Project Structure

- `apps/web`: Next.js application for the Mentor Dashboard and API.
- `docs`: Project documentation and planning artifacts.

## Getting Started

1.  Navigate to `apps/web`:
    ```bash
    cd apps/web
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```
